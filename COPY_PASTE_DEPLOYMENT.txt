===============================================================================
                         DEPLOYMENT ORDER CHECKLIST
===============================================================================

□ Step 1: Deploy MinIO
  ├─ Create empty service named "minio"
  ├─ Set Dockerfile path: Dockerfile.minio
  ├─ Copy environment variables
  └─ Wait for deployment to complete

□ Step 2: Deploy Backend
  ├─ Create GitHub repo service named "backend"
  ├─ Set root directory: backend
  ├─ Set Dockerfile path: backend/Dockerfile
  ├─ Enable public domain in Settings → Networking
  ├─ Copy environment variables (except FRONTEND_URL)
  ├─ Wait for deployment to complete
  └─ 📝 SAVE THE PUBLIC DOMAIN URL!

□ Step 3: Deploy Frontend
  ├─ Create GitHub repo service named "frontend"
  ├─ Set root directory: frontend
  ├─ Set Dockerfile path: frontend/Dockerfile
  ├─ Enable public domain in Settings → Networking
  ├─ Update NEXT_PUBLIC_API_URL with backend domain
  ├─ Wait for deployment to complete
  └─ 📝 SAVE THE PUBLIC DOMAIN URL!

□ Step 4: Connect Services
  ├─ Go back to Backend service
  ├─ Add FRONTEND_URL variable with frontend domain
  └─ Restart backend service

□ Step 5: Test Application
  ├─ Open frontend URL in browser
  ├─ Test backend health: https://[backend-domain]/health
  └─ Try user registration/login
