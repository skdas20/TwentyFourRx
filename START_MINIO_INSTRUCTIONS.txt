========================================
   HOW TO START MINIO (D: DRIVE)
========================================

STEP 1: Copy the batch file
----------------------------
Copy "start-minio.bat" from your project root to D:\minio\

STEP 2: Start MinIO
----------------------------
Double-click: D:\minio\start-minio.bat

OR manually run in PowerShell:
cd D:\minio
$env:MINIO_ROOT_USER="minioadmin"
$env:MINIO_ROOT_PASSWORD="minioadmin123"
.\minio.exe server D:\minio\data --console-address ":9001"

STEP 3: Verify it's running
----------------------------
Open browser: http://localhost:9001
Login: minioadmin / minioadmin123

========================================
   WHAT MINIO DOES
========================================

- Stores listing documents (invoices, receipts)
- All files saved to D:\minio\data\
- Sellers upload documents when creating listings
- Admins can view documents when approving listings

========================================
   TROUBLESHOOTING
========================================

Problem: Port already in use
Solution: Close any app using port 9000 or 9001

Problem: Permission denied
Solution: Run as Administrator

Problem: Can't access console
Solution: Check if MinIO is running, restart if needed
