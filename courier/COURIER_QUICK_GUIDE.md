## How to Use

### 1. Login
1. Go to https://track.24rxexchange.in
2. Enter your email and password
3. Click "Sign In"

### 2. View Deliveries
- All your assigned deliveries appear in the table
- Use the search box to find specific orders
- Use the status filter to see deliveries by status

### 3. Update Delivery Status

#### When You Pick Up a Package:
1. Click "View Details" on the delivery
2. Click "Mark as Picked Up"
3. The status changes to "In Transit"
4. Buyer receives notification with tracking number

#### When Out for Delivery:
1. Open the delivery details
2. Click "Mark Out for Delivery"
3. Buyer gets notified

#### When Delivered:
1. Open the delivery details
2. Click "Mark as Delivered"
3. System generates OTP for buyer
4. Buyer must enter OTP to confirm receipt

---

## Delivery Status Flow

```
1. Awaiting Pickup → You need to pick up the package
2. In Transit → Package is with you
3. Out for Delivery → You're on the way to deliver
4. Pending OTP → Delivered, waiting for buyer confirmation
5. Delivered → Complete! ✅
```

## Safety Guidelines

### Medicine Handling
1. Keep medicines in original packaging
2. Protect from heat, moisture, and sunlight
3. Don't open sealed packages
4. Handle with clean hands
5. Store in cool, dry place during transit

### Delivery Safety
1. Verify buyer identity before delivery
2. Get confirmation (OTP) before leaving
3. Take photo proof if needed
4. Report any suspicious activity
5. Follow traffic rules

## Frequently Asked Questions

**Q: What if the buyer is not available?**
A: Mark as "Delivery Attempted" and coordinate with buyer for rescheduling.

**Q: What if the package is damaged?**
A: Don't accept it. Contact admin immediately.

**Q: Can I deliver to someone else if buyer is unavailable?**
A: Only with buyer's explicit permission and OTP.

**Q: What if I lose the package?**
A: Contact admin immediately. This is a serious issue.

**Q: How do I get paid?**
A: Payment details will be provided by admin separately.

**Q: Can I see other couriers' deliveries?**
A: No, you can only see deliveries assigned to you.
